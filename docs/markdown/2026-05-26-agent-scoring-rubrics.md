# ArchCritic 方案阶段专项 Agent 细化评分卡

生成日期：2026-05-26  
适用范围：方案阶段多 Agent 评图流程  
适用对象：功能与流线 Agent、场地 Agent、几何形式 Agent、结构 Agent、综合评审 Agent  

## 1. 文档目的

本文档用于把现有“评分项 + 分值权重”进一步细化为可供 AI 读取的评分卡。目标不是让系统替代教师给出绝对分数，而是让不同 Agent 在评图时使用更稳定、更接近建筑院系设计课评图习惯的判断标准。

评分卡强调三点：

1. 每个分项都有明确的分档标准，减少模型自由发挥。
2. 每条扣分或表扬都必须尽量对应图纸证据、设计说明或知识库依据。
3. 对 AI 难以从图纸准确判断的内容，只做“可见线索层面”的判断，不能假装完成工程计算。

## 2. 总体评分原则

### 2.1 评分对象

方案阶段主要评价“设计方案是否具备继续深化的基础”，不是施工图审查，也不是结构计算审查。

AI 可以评价：

- 图纸中清楚表达的功能关系、空间组织、入口关系、室内外联系。
- 设计说明中明确写出的设计意图、功能定位和空间策略。
- 平面、总图、分析图、效果图中可见的形体、流线、场地和结构意向。
- 知识库中与当前问题直接相关的评价原则、案例经验和常见问题。

AI 不应硬判：

- 柱、梁、板的具体尺寸是否满足规范。
- 结构构件的真实承载力、配筋、抗震性能。
- 消防疏散距离、楼梯宽度、无障碍坡度等需要精确尺寸的规范符合性。
- 未上传图纸范围内的楼层、剖面、立面或场地信息。
- 标注模糊、图纸分辨率不足时无法确认的内容。

### 2.2 分数使用方式

每个专项 Agent 满分 100 分。各分项按当前系统权重评分。

推荐分档：

| 档位 | 百分比 | 含义 |
|---|---:|---|
| 优秀 | 85%-100% | 设计逻辑清楚，图纸证据充分，问题较少，可作为继续深化的基础 |
| 良好 | 70%-84% | 基本成立，有局部问题，但不会明显阻碍下一轮深化 |
| 合格 | 60%-69% | 核心关系基本可读，但存在明显薄弱点，需要重点修改 |
| 较弱 | 40%-59% | 关键关系不清楚或多处冲突，方案需要较大调整 |
| 严重不足 | 0%-39% | 缺少关键表达，或存在会阻碍方案成立的核心问题 |

### 2.3 证据与置信度

Agent 必须先判断证据等级，再决定分数强度。

| 证据等级 | 使用方式 |
|---|---|
| 高置信证据 | 图纸清晰可见，且设计说明一致；可进入 must_fix、strengths 和明确评分理由 |
| 中置信证据 | 图纸大体可见，但局部标注或边界不清；可作为 should_improve，不宜写成严重硬伤 |
| 低置信证据 | 图纸模糊、缺少关键图纸、只能靠推测；应写入 uncertain_observations 或 missing_information |

通用封顶规则：

- 缺少本专项最关键图纸时，该专项总分通常不应高于 65 分。
- 只有一张局部平面图时，不得对整栋建筑、完整场地或完整结构作确定结论。
- 如果设计说明明确提到某内容存在，但图纸看不清，应写“不确定”，不得直接写“缺失”。
- 如果图纸可见明显冲突，且设计说明不能解释，可写入 must_fix。

## 3. 输出字段建议

每个专项 Agent 建议继续使用现有结构：

```json
{
  "observed_facts": ["图纸或说明中已确认的事实"],
  "confidence": "high / medium / low",
  "summary": "专项摘要",
  "sub_scores": {
    "分项名称": {
      "score": 0,
      "max_score": 25,
      "reason": "为什么给这个分数",
      "evidence": "来自哪张图纸、设计说明或知识库编号"
    }
  },
  "must_fix": ["确定的必须修改问题"],
  "should_improve": ["建议优先优化的问题"],
  "optional_improvements": ["可选深化建议"],
  "strengths": ["值得保留的优势"],
  "missing_information": ["缺失但影响判断的信息"],
  "uncertain_observations": ["看不清或只能推测的内容"]
}
```

每个分项评分理由应优先包含：

- 看到了什么。
- 这说明什么。
- 为什么扣分或加分。
- 依据来自图纸、说明还是知识库。

## 4. 功能与流线 Agent 评分卡

适用图纸：平面图优先，其次是总图、功能分析图、流线分析图、设计说明。  
核心问题：功能是否完整，分区是否合理，流线是否清楚，平面是否有设计性。

### 4.1 功能满足，满分 30 分

评价内容：是否满足任务书或建筑类型的基本功能要求。

| 分数 | 判断标准 |
|---:|---|
| 26-30 | 主要功能完整，公共、辅助、管理、服务空间关系清楚；图纸和说明能互相印证 |
| 21-25 | 主要功能基本完整，少量辅助空间或服务空间表达不足，但不影响方案基本成立 |
| 16-20 | 核心功能大体存在，但若干关键空间缺失、面积关系明显失衡或功能定位不清 |
| 8-15 | 多个核心功能缺失或混杂，难以支撑建筑类型的基本使用 |
| 0-7 | 缺少平面图或任务信息，无法判断功能是否成立；不得编造具体缺失空间 |

证据要求：

- 优先引用平面图中的房间名称、空间位置和设计说明。
- 如果任务书缺失，只能按该建筑类型的基本常识评价，不能写“未满足任务书”。
- 如果某空间在说明中出现但图纸看不清，应写入 uncertain_observations。

常见 must_fix 触发条件：

- 图纸中明确缺少建筑类型的核心功能空间。
- 主要功能被安排在明显不适合的位置，导致使用逻辑不成立。
- 公共空间、后勤服务、管理空间完全混杂，影响基本运营。

### 4.2 功能分区，满分 25 分

评价内容：动静分区、内外分区、公共与后勤分区、开放与私密分区是否合理。

| 分数 | 判断标准 |
|---:|---|
| 22-25 | 分区层次清楚，公共、半公共、私密、服务空间有明确过渡，互相干扰少 |
| 18-21 | 分区基本合理，局部空间关系略紧张或过渡不足 |
| 13-17 | 分区可以识别，但动静、内外或服务关系存在明显混杂 |
| 6-12 | 多个功能区互相穿插，空间使用容易产生干扰 |
| 0-5 | 平面无法读出基本分区，或缺少可判断的平面信息 |

证据要求：

- 需要指出具体分区关系，例如入口大厅与公共功能、后勤与主要公共空间、安静空间与活动空间的相对位置。
- 不能只写“分区混乱”，必须说明哪类空间与哪类空间发生冲突。

常见 should_improve 触发条件：

- 门厅与主要功能空间缺少清楚转换。
- 服务用房贴近主要公共空间但缺少缓冲。
- 安静空间被高人流空间包围。

### 4.3 流线分析，满分 25 分

评价内容：公众流线、内部管理流线、后勤服务流线、车行或停车到达是否顺畅。

| 分数 | 判断标准 |
|---:|---|
| 22-25 | 主要入口清楚，公众流线连续，后勤或管理流线相对独立，节点组织清晰 |
| 18-21 | 主要流线基本顺畅，局部绕行、交叉或节点识别不足 |
| 13-17 | 能读出主要流线，但入口、核心筒、走廊或节点组织存在明显低效 |
| 6-12 | 公众、内部或后勤流线多处交叉，容易造成使用冲突 |
| 0-5 | 缺少平面或入口信息，无法判断流线；不得臆测完整动线 |

证据要求：

- 优先识别主入口、门厅、竖向交通、主要走廊、服务入口和车库入口。
- 如果只上传一层平面，只能评价该层流线，不得推断其他楼层。
- 流线问题必须说清“从哪里到哪里”的路径问题。

常见 must_fix 触发条件：

- 后勤流线明显穿越主要公共大厅或主要展厅、阅览区、活动区。
- 主入口无法被识别，导致到达路径不成立。
- 车行入口与主要步行入口明显冲突，且图纸没有缓冲或分离措施。

### 4.4 平面丰富性，满分 20 分

评价内容：平面是否具有空间层次、节点变化、公共空间组织和一定设计趣味。

| 分数 | 判断标准 |
|---:|---|
| 17-20 | 平面组织有清楚的空间序列、节点层次和几何秩序，功能与空间体验结合较好 |
| 14-16 | 平面有一定层次和变化，但局部仍偏机械或节点表达不足 |
| 10-13 | 平面基本满足使用，但空间体验较平淡，公共空间缺少层次 |
| 5-9 | 平面主要是房间堆砌，缺少公共节点和空间组织意识 |
| 0-4 | 缺少可判断的平面信息，或平面组织严重不可读 |

证据要求：

- 只评价平面空间组织，不评价立面风格。
- 不应把“造型复杂”直接等同于“平面丰富”。
- 平面丰富性应与功能、流线共同判断，不能只看图形是否有变化。

## 5. 场地 Agent 评分卡

适用图纸：总平面、场地分析图、首层平面、交通分析图、景观或室外空间说明。  
核心问题：方案是否理解场地，建筑与城市、入口、边界、室外空间是否有回应。

### 5.1 场地解读，满分 25 分

评价内容：是否识别场地边界、道路、朝向、周边界面、重要景观或限制条件。

| 分数 | 判断标准 |
|---:|---|
| 22-25 | 场地条件被清楚识别，建筑布局能回应道路、边界、朝向和主要环境关系 |
| 18-21 | 基本理解场地，能回应主要道路或入口方向，但环境关系表达略粗 |
| 13-17 | 只回应了局部条件，场地边界、城市界面或朝向关系不够清楚 |
| 6-12 | 建筑更像被放置在地块中，缺少对周边条件的判断 |
| 0-5 | 缺少总图或场地信息，无法判断场地解读水平 |

证据要求：

- 优先引用总平面中的道路、边界、入口、朝向、周边建筑或景观。
- 如果没有总图，不能直接判定“场地回应差”，应说明缺少判断依据。

常见 should_improve 触发条件：

- 图纸有地块但缺少北向、道路或主入口方向。
- 建筑主要开放面与城市到达方向关系不清。
- 场地分析图与总平面策略没有对应关系。

### 5.2 总图组织，满分 25 分

评价内容：建筑、道路、停车、景观、广场、后勤区在总图中的组织是否清楚。

| 分数 | 判断标准 |
|---:|---|
| 22-25 | 建筑布局、外部交通、室外空间和后勤服务关系清楚，整体秩序稳定 |
| 18-21 | 总体组织基本成立，局部停车、后勤或景观空间关系需要优化 |
| 13-17 | 建筑与场地之间有基本关系，但室外空间和交通组织不够清楚 |
| 6-12 | 总图元素堆放明显，道路、建筑、景观和停车互相干扰 |
| 0-5 | 缺少总平面或总图无法读出基本组织 |

证据要求：

- 评价应指出建筑体量、道路、停车、广场、绿地或后勤的位置关系。
- 不应因为图面风格简洁就判定总图组织差。

常见 must_fix 触发条件：

- 主入口广场、停车或后勤区关系明显冲突。
- 建筑主要出入口面对不合理的边界或死角。
- 消防、车行、步行关系完全不可读。注意：没有尺寸时不能判定消防规范不合格，只能判定表达不足。

### 5.3 入口与到达，满分 25 分

评价内容：城市到达、主入口、次入口、后勤入口、车行入口和步行路径是否清楚。

| 分数 | 判断标准 |
|---:|---|
| 22-25 | 主入口识别强，到达序列清楚，人行、车行、后勤入口有合理分离和过渡 |
| 18-21 | 主入口基本明确，局部到达路径或前场空间组织偏弱 |
| 13-17 | 可以找到入口，但人车、主次或后勤关系存在明显混杂 |
| 6-12 | 主入口不清或到达路径绕行，主要入口关系影响使用 |
| 0-5 | 缺少入口相关图纸或入口完全无法识别 |

证据要求：

- 必须说明主入口从哪条道路或哪个场地空间进入。
- 如果图纸只标出门洞但没有总图，不宜强判城市到达问题。
- 车行和人行冲突需要图纸明确显示路径重叠或交叉。

常见 must_fix 触发条件：

- 主入口与后勤入口混用，且穿越主要公共空间。
- 车行入口直接压迫主入口广场或主要步行路径。
- 主入口无法被识别，导致公共建筑形象和使用逻辑不成立。

### 5.4 环境回应，满分 25 分

评价内容：建筑是否回应朝向、景观、噪声、开放空间、气候和场地体验。

| 分数 | 判断标准 |
|---:|---|
| 22-25 | 建筑布局与室外空间、景观视线、朝向和公共活动形成积极关系 |
| 18-21 | 有基本环境回应，局部空间界面或室外活动组织可继续深化 |
| 13-17 | 有环境回应意图，但图纸表达较弱或与建筑布局联系不足 |
| 6-12 | 室内外关系薄弱，开放空间像剩余空间，缺少明确使用 |
| 0-5 | 缺少可判断的环境、景观或场地表达 |

证据要求：

- 可依据庭院、广场、架空、廊道、景观轴线、开口方向等进行判断。
- 没有日照、风环境或噪声数据时，不得做精确环境性能结论。

常见 should_improve 触发条件：

- 室外空间有形状但缺少入口、活动或公共功能支撑。
- 建筑主要公共空间与景观资源没有建立联系。
- 设计说明强调环境回应，但图纸没有对应策略。

## 6. 几何形式 Agent 评分卡

适用图纸：平面图、形体分析图、概念分析图、效果图、模型图、设计说明。  
核心问题：形式是否有生成逻辑，几何是否服务空间和功能，而不是孤立造型。

### 6.1 形体生成，满分 25 分

评价内容：形体是否来自场地、功能、流线、结构或概念逻辑。

| 分数 | 判断标准 |
|---:|---|
| 22-25 | 形体生成逻辑清楚，能从图纸或说明中看到由场地、功能或空间策略推动的过程 |
| 18-21 | 形体有明确意图，但生成过程或与实际平面的对应略弱 |
| 13-17 | 有概念说法，但形体与功能、场地或流线联系不充分 |
| 6-12 | 形体主要表现为外观造型，缺少可解释的生成依据 |
| 0-5 | 缺少形体表达或形体逻辑完全不可读 |

证据要求：

- 需要对应设计说明、分析图、平面轮廓或效果图。
- 不能只因外形复杂就判定生成逻辑优秀。

常见 should_improve 触发条件：

- 概念文字很强，但平面和体量没有体现。
- 形体变化没有带来空间、采光、流线或场地收益。

### 6.2 空间构图，满分 25 分

评价内容：空间主次、轴线、节点、虚实、围合和开放关系是否清楚。

| 分数 | 判断标准 |
|---:|---|
| 22-25 | 空间主次分明，公共节点和空间序列清楚，构图有稳定秩序 |
| 18-21 | 构图基本成立，局部节点或空间过渡可加强 |
| 13-17 | 有构图意图，但主次关系、节点或空间序列不够明确 |
| 6-12 | 空间构图松散，多个空间关系缺少组织核心 |
| 0-5 | 无法从图纸中判断空间构图，或空间关系严重混乱 |

证据要求：

- 可通过门厅、中庭、庭院、主轴、环路、公共节点、体量围合等判断。
- 不应把图面排版美观等同于空间构图优秀。

常见 must_fix 触发条件：

- 主要公共空间没有清楚位置或组织作用。
- 入口、核心公共空间和主要功能之间缺少构图关系。

### 6.3 几何秩序，满分 25 分

评价内容：几何关系是否统一，曲直、网格、轴线、模块、边界是否有控制。

| 分数 | 判断标准 |
|---:|---|
| 22-25 | 几何系统清楚，变化有规则，空间和结构有可继续深化的秩序 |
| 18-21 | 几何基本统一，局部转折、边界或节点处理可优化 |
| 13-17 | 几何语言可识别，但局部关系混杂或缺少控制 |
| 6-12 | 几何形态随意，曲线、斜线、网格或边界互相冲突 |
| 0-5 | 缺少可判断图纸，或几何关系完全不可读 |

证据要求：

- 可依据平面轮廓、柱网意向、空间边界、庭院形态、轴线或模块判断。
- AI 不应判断精确模数是否符合施工要求，只能判断几何秩序是否清楚。

常见 should_improve 触发条件：

- 局部房间被外形挤压成难用的边角空间。
- 主要几何系统与功能分区不匹配。
- 曲线或斜线造型导致空间边界过碎。

### 6.4 形式功能协同，满分 25 分

评价内容：形式是否支持功能、流线、空间体验和结构意向。

| 分数 | 判断标准 |
|---:|---|
| 22-25 | 形式与功能、流线、公共空间和结构意向相互支持，设计表达统一 |
| 18-21 | 形式与功能基本一致，局部空间因造型产生小问题 |
| 13-17 | 形式有表现力，但与功能或流线联系一般 |
| 6-12 | 形式明显压迫功能，造成房间难用、流线绕行或空间浪费 |
| 0-5 | 形式与功能严重脱节，或缺少足够图纸判断 |

证据要求：

- 必须结合功能分区、流线或空间节点判断。
- 不应只根据效果图观感给高分。

常见 must_fix 触发条件：

- 形体造型导致核心功能空间难以使用。
- 主要公共流线被形式扭曲，出现明显绕行或断裂。
- 形式表达与设计说明核心概念明显不一致。

## 7. 结构 Agent 评分卡

适用图纸：平面图、结构意向图、剖面图、效果图、设计说明。  
核心问题：结构意向是否可读，跨度和支撑关系是否大体合理，结构是否支持空间，而不是做工程计算。

重要边界：

AI 通常无法从方案图中准确判断柱子尺寸、梁高、板厚、配筋、节点构造和真实承载力。因此结构 Agent 的评价应定位为“建筑方案阶段结构意向与可行性初判”，不能写成正式结构审查。

### 7.1 结构体系，满分 30 分

评价内容：方案是否表达出基本结构体系，如框架、筒体、墙体、桁架、拱、壳、混合体系等结构意向。

| 分数 | 判断标准 |
|---:|---|
| 26-30 | 结构体系意向清楚，支撑逻辑与平面、空间和体量基本一致 |
| 21-25 | 结构体系大体可读，但局部柱网、墙体或核心筒表达不足 |
| 16-20 | 能推测结构体系，但图纸缺少明确支撑信息，需要补充表达 |
| 8-15 | 结构意向模糊，空间和形体难以看出如何被支撑 |
| 0-7 | 缺少可判断结构线索，不得判定具体结构失败，只能说明表达不足 |

证据要求：

- 可依据柱点、墙体、核心筒、大跨空间边界、剖面或说明判断。
- 如果没有结构图，不能要求施工图级别表达，但可以要求方案级结构意向更清楚。

常见 should_improve 触发条件：

- 平面没有柱网或支撑提示，但存在较大公共空间。
- 结构说明与图纸看不到对应关系。
- 核心筒或竖向交通与结构组织关系不清。

### 7.2 跨度与支撑，满分 25 分

评价内容：大空间、悬挑、架空、开洞、曲面或复杂形体是否有大体可理解的支撑关系。

| 分数 | 判断标准 |
|---:|---|
| 22-25 | 大空间和支撑关系清楚，跨度意向与结构体系基本匹配 |
| 18-21 | 大空间基本可行，但局部支撑、边界或转换关系需要说明 |
| 13-17 | 存在较大空间或复杂形体，但支撑逻辑表达不足 |
| 6-12 | 大跨度、悬挑或架空较明显，却缺少可靠支撑线索 |
| 0-5 | 图纸无法判断跨度与支撑，不得推断具体构件尺寸不合格 |

证据要求：

- AI 可以判断“是否有支撑线索”，不能判断“梁高是否够”。
- 对曲面、悬挑、超大开洞等，应要求补充结构意向，而不是直接判定不可建。

常见 must_fix 触发条件：

- 图纸明确显示大面积悬挑或架空，但完全没有支撑、拉结或结构说明。
- 主要大空间上方或周边缺少任何可见结构组织，影响方案可信度。

### 7.3 构造可行性，满分 25 分

评价内容：方案的形体、空间和材料表达是否具有基本建造逻辑。

| 分数 | 判断标准 |
|---:|---|
| 22-25 | 构造意向与形体、空间和材料表达基本一致，复杂部位有可理解的处理线索 |
| 18-21 | 总体可行，局部连接、屋面、开洞或外皮需要深化 |
| 13-17 | 有建造意图，但复杂形体、曲面或悬挑缺少构造说明 |
| 6-12 | 方案依赖较复杂构造，但图纸几乎没有解释，可信度较弱 |
| 0-5 | 缺少构造相关信息，无法判断；不得写成确定工程错误 |

证据要求：

- 可参考剖面、节点示意、材料说明、效果图中的构件逻辑。
- 不能根据效果图直接判断材料厚度、节点做法或造价。

常见 should_improve 触发条件：

- 屋顶、曲面、幕墙或大开洞只有效果表达，没有构造解释。
- 室内大空间与外部造型之间缺少剖面说明。

### 7.4 结构空间协同，满分 20 分

评价内容：结构是否支持空间体验，柱、墙、核心筒是否与功能、流线和公共空间协调。

| 分数 | 判断标准 |
|---:|---|
| 17-20 | 结构线索与公共空间、功能分区、流线和形体表达协同，形成设计秩序 |
| 14-16 | 结构与空间基本协调，局部支撑可能影响使用或表达 |
| 10-13 | 结构意向与空间关系较弱，可能需要重新整合 |
| 5-9 | 支撑或核心筒位置明显干扰主要空间或流线 |
| 0-4 | 缺少结构线索，无法判断结构与空间协同 |

证据要求：

- 可通过柱点、墙体、核心筒、竖向交通和大空间位置判断。
- 若图纸没有柱网，不应臆测柱子会挡路，只能写“缺少支撑表达，无法确认是否干扰空间”。

常见 must_fix 触发条件：

- 可见柱、墙或核心筒明显占据主要公共流线或核心空间。
- 大空间与支撑系统完全脱节，影响方案继续深化。

## 8. 综合评审 Agent 汇总规则

综合评审 Agent 不再单独新增评分项，最终综合分应来自专项 Agent 分数的汇总。当前建议：

- 功能与流线：30%
- 场地与回应：25%
- 几何形式：20%
- 结构与可行性：25%

如果后续课程更重视功能训练，可临时调整为：

- 功能与流线：35%
- 场地与回应：25%
- 几何形式：20%
- 结构与可行性：20%

综合评审应遵守：

1. 不新增专项 Agent 没有支持的事实。
2. 不把 uncertain_observations 升级成 must_fix。
3. 优先汇总跨专项重复出现的问题。
4. 优先保留会阻碍下一轮深化的问题。
5. 最终报告中的知识库编号必须来自专项结果或当次知识库快照。

## 9. 问题严重程度判定

### 9.1 must_fix

必须同时满足：

- 图纸或说明证据清楚。
- 问题会影响建筑方案基本成立或下一轮深化。
- 不是单纯审美偏好。
- 不是因为缺图导致的猜测。

典型问题：

- 主入口无法识别。
- 后勤流线穿越主要公共空间。
- 核心功能缺失。
- 大跨度或悬挑完全没有支撑线索。
- 形式严重压迫功能使用。

### 9.2 should_improve

适合写入：

- 基本方案成立，但局部关系需要优化。
- 有一定证据，但还不到严重硬伤。
- 下一轮修改中优先处理会明显提升方案质量的问题。

### 9.3 optional_improvements

适合写入：

- 深化表达、空间体验、图纸说明、案例参考等提升项。
- 不影响方案基本成立，但能提高完整度和专业性。

### 9.4 missing_information

适合写入：

- 缺少总图、剖面、结构意向图、任务书、面积表、流线分析图等。
- 缺失信息影响判断，但不能直接等同于设计错误。

### 9.5 uncertain_observations

适合写入：

- 图纸模糊。
- 标注不可读。
- 设计说明说有，但图纸看不清。
- 图纸之间可能矛盾，但无法确认。

## 10. AI 读取时的压缩版本建议

后续如果把本文档接入提示词，不建议整篇全文一次性塞入模型。更稳妥的方式是按当前 Agent 只注入对应章节，例如：

- 功能与流线 Agent 只读取第 2、3、4、9 节。
- 场地 Agent 只读取第 2、3、5、9 节。
- 几何形式 Agent 只读取第 2、3、6、9 节。
- 结构 Agent 只读取第 2、3、7、9 节。
- 综合评审 Agent 只读取第 2、8、9 节。

提示词中可加入统一约束：

```text
请严格按照评分卡分档给分。每个分项必须先判断证据等级，再选择分数区间。
如果证据不足，不得给出高置信硬性结论；应降低分数上限，并写入 missing_information 或 uncertain_observations。
```

## 11. 后续落地建议

建议把评分卡拆成结构化配置，避免提示词越写越长。每个分项可整理为：

```json
{
  "name": "入口与到达",
  "max_score": 25,
  "excellent": "22-25：主入口识别强，到达序列清楚，人行、车行、后勤入口有合理分离和过渡",
  "good": "18-21：主入口基本明确，局部到达路径或前场空间组织偏弱",
  "pass": "13-17：可以找到入口，但人车、主次或后勤关系存在明显混杂",
  "weak": "6-12：主入口不清或到达路径绕行，主要入口关系影响使用",
  "severe": "0-5：缺少入口相关图纸或入口完全无法识别",
  "evidence_required": "说明主入口从哪条道路或哪个场地空间进入",
  "must_fix_triggers": ["主入口与后勤入口混用", "车行入口压迫主入口广场", "主入口无法识别"],
  "uncertain_triggers": ["缺少总图", "入口标注模糊", "只有局部平面无法判断城市到达"]
}
```

这样后续可以让不同 Agent 只读取自己需要的评分卡，既保持专业性，也避免超过模型上下文和 5 分钟评审时间预算。
