# ArchCritic 分数等级体系设计方案

## 设计目标

分数等级的核心改为“游戏化激励”：让学生看到分数变化时，不只是知道涨了几分，还能获得类似升级、晋级、拿到新奖牌的反馈。它参考多邻国这类产品的等级体系，用清楚的段位、亮眼的奖牌和短句反馈，给用户一点乐趣，并鼓励继续提高分数。

这个体系不是正式评分标准，而是一个轻量的学习激励层。它只服务一个目标：让用户愿意继续修改方案，把下一版做得更高。

## 展示范围

等级只显示在历史版本对比页右上角的“分数变化”区域，不放到报告页、侧栏、折线悬浮卡片里，避免页面到处都在重复等级。

推荐显示格式：

```text
[黄金奖牌]  +8 分 · 黄金
           可以，金牌味儿出来了。
```

显示规则：

- 只有项目至少有两个已评分版本时显示，因为这里对应“本版相对上一版”的变化。
- 等级按当前最新评分版本计算。
- 分数上涨时用更强的正反馈：奖牌亮起、短暂放大、扫光一次。
- 分数下降但没跨档时，只提示掉分和“守住当前段位”。
- 分数下降并跨到更低一档时，明确显示“掉段”，但语气要轻松，不羞辱用户。
- 低分也给段位，不写“失败”“不合格”，让用户觉得还有继续冲分的空间。

## 参考多邻国的设计思路

不直接照搬具体视觉，而是借用它的三类体验：

1. 清晰段位：用户一眼知道自己在哪个等级，以及下一档是什么。
2. 晋级反馈：升级时有明确的视觉奖励，例如奖牌发光、星光、彩带、扫光。
3. 轻量压力：下降时提示“快要掉段”或“需要守住”，但不羞辱用户。

ArchCritic 的版本对比页可以把“分数变化”做成一个小型段位结算区。每次评图后，用户看到的不只是 `+8 分`，而是“我从白银冲到黄金了”。

## 等级划分

分级保持五档：60 分以下一档，60 分以上每 10 分一档。名称采用游戏段位，直观、有竞争感，也容易做奖牌视觉。

| 分数区间 | 默认段位 | 段位含义 | 奖牌风格 |
| --- | --- | --- | --- |
| 0-59 | 青铜 | 还在起步，但已经进入挑战 | 暖铜色圆牌，边缘略粗，有基础火苗 |
| 60-69 | 白银 | 方案能跑起来，开始有稳定基础 | 银白圆牌，带浅蓝高光 |
| 70-79 | 黄金 | 主要关系成立，进入明显提分区 | 金色圆牌，带星形刻印 |
| 80-89 | 铂金 | 完成度较高，进入高分竞争区 | 冷白金属牌，带紫蓝光边 |
| 90-100 | 钻石 | 高质量成果，接近展示级作品 | 钻石徽章，带强高光和冠状切面 |

## 段位名称

| 分数区间 | 名称 |
| --- | --- |
| 0-59 | 青铜 |
| 60-69 | 白银 |
| 70-79 | 黄金 |
| 80-89 | 铂金 |
| 90-100 | 钻石 |

已确定使用标准游戏段位，也就是 A 方案。它最简单、最直观，用户不用解释就能理解，也最适合做奖牌图标。当前不做 `I / II / III` 这类段内小级别，避免等级系统变复杂。

## 每档评语语料库

右上角只显示一句短评。文案要有游戏化的乐趣，但仍然围绕设计修改，不要变成纯娱乐。

### 0-59：青铜

- 青铜开局，别慌，先把主线跑通。
- 现在还不是炫技的时候，先把空间关系站起来。
- 这版有点像刚开局，手别抖，白银不远。
- 先把基础盘稳住，后面才好一路加分。
- 这一版先当热身，下一版开始认真上分。

### 60-69：白银

- 白银到手，方案终于不飘了。
- 这版能看出路子了，再改几处就能冲黄金。
- 基础盘稳住了，别松手，分数还能往上拱。
- 有点意思了，下一步把关键问题挨个收掉。
- 白银先坐稳，黄金已经在前面招手。

### 70-79：黄金

- 黄金到手，这版开始有点像样了。
- 可以，金牌味儿出来了，继续把亮点拎清楚。
- 主要逻辑已经能打，别让小毛病偷分。
- 这版挺争气，下一步拼完成度。
- 黄金稳住了，再抠一轮细节就能摸铂金。

### 80-89：铂金

- 铂金了，方案已经很能打。
- 这版不是小修小补能来的，确实有进步。
- 主要问题少多了，现在拼的是精修和气质。
- 已经挺亮了，再稳一点就能冲钻石。
- 铂金别飘，最后这几分最难也最值钱。

### 90-100：钻石

- 钻石达成，这版可以拿出来亮一亮了。
- 高分区站住了，方案确实有东西。
- 这不是运气分，可以整理成阶段成果了。
- 钻石别掉，最后检查一遍表达一致性。
- 已经接近封顶，别在收尾处丢小分。

## 掉段语料库

掉段文案要有轻微压力，但不能打击人。语气像一个熟悉的助教提醒你：“掉了，别慌，知道该补哪儿就能打回来。”

### 掉到青铜

- 掉回青铜了，先别急，主线捋顺还能打回来。
- 这版有点乱，像桌面被风吹了，先把关键关系收回来。
- 青铜重新开局，先保清晰度，再谈亮点。

### 掉到白银

- 掉到白银了，问题不大，先把基础盘守住。
- 这版有点松，黄金先借你放一边，改回来再拿。
- 白银守段中，先把最影响分数的地方补回来。

### 掉到黄金

- 掉到黄金了，说明底子还在，但细节开始扣分了。
- 金牌还在手里，只是光暗了一点，下一版擦亮。
- 这版没崩，主要是几个问题把铂金挡住了。

### 掉到铂金

- 掉到铂金了，离钻石不远，别被最后几分卡住。
- 钻石先缓一缓，这版先把精度找回来。
- 高分区还在，补掉关键短板就能再冲上去。

## 奖牌图标设计

### 总体概念

图标直接做奖牌，不再绕成建筑图纸隐喻。奖牌要有强识别度：圆形主牌、顶部绶带、中心符号、材质高光。不同段位通过材质和中心符号区分，形成类似游戏段位的收集感。

奖牌要比普通小图标更有存在感，但仍然放在右上角的小区域里，不能压过分数变化文字。

### 基础规格

| 项目 | 规格 |
| --- | --- |
| 默认尺寸 | 32px × 32px |
| 展示位置 | 右上角分数变化左侧 |
| 图形格式 | 推荐 SVG，支持渐变和高光 |
| 主体结构 | 上方 V 形绶带 + 下方圆形奖牌 |
| 圆牌边框 | 2px 到 3px，形成厚重感 |
| 中心图案 | 每档一个不同符号，不能只靠颜色区分 |
| 动效时间 | 500ms 以内，只播放一次 |
| 背景 | 不加大色块，奖牌本身承担视觉焦点 |

### 五档奖牌细节

| 分数区间 | 奖牌名 | 主色 | 中心符号 | 细节 |
| --- | --- | --- | --- | --- |
| 0-59 | 青铜奖牌 | 铜棕 `#b86b32` + 深铜 `#7a3f1d` | 小火苗 | 圆牌边缘厚一点，火苗表示刚启动；高光较弱，避免太华丽。 |
| 60-69 | 白银奖牌 | 银灰 `#c7d0d9` + 冷蓝 `#7f9db8` | 上升箭头 | 金属反光更明显，箭头表示开始上分。 |
| 70-79 | 黄金奖牌 | 金黄 `#f0b429` + 深金 `#a86f00` | 五角星 | 经典金牌感，中心星星表示方案开始有亮点。 |
| 80-89 | 铂金奖牌 | 铂金白 `#e5e7eb` + 紫蓝 `#6c5ce7` | 闪电星 | 边缘加一圈紫蓝光，体现高阶段位。 |
| 90-100 | 钻石奖牌 | 冰蓝 `#8be9ff` + 深蓝紫 `#4f46e5` | 钻石切面 | 圆牌可改成多边形徽章，顶部高光更强，形成封顶感。 |

### 段位递进

视觉上要让用户感觉“越高越稀有”：

1. 青铜：材质偏暗，只有小火苗。
2. 白银：亮度提高，出现上升箭头。
3. 黄金：颜色最直观，中心星星更醒目。
4. 铂金：加入光边和更冷的高级感。
5. 钻石：形状变化最大，从圆牌升级成钻石徽章。

### 晋级动效

当当前版本比上一版本段位更高时，播放一次晋级反馈：

1. 奖牌从 0.85 倍放大到 1.08 倍，再回到 1 倍。
2. 奖牌表面扫过一道斜向高光。
3. 奖牌周围出现 3 到 5 个小星点，300ms 后消失。
4. 文案使用晋级语气，例如：`晋级黄金！这一版明显更稳了。`

不要做满屏庆祝，只在右上角小区域完成反馈。

### 掉段反馈

当当前版本比上一版本段位更低时，明确显示“掉段”。参考多邻国“降级提醒”的思路，制造一点可感知的失落感，但不要做羞辱式反馈。

右上角显示格式：

```text
[白银奖牌]  -7 分 · 掉到白银
           黄金先借你放一边，改回来再拿。
```

视觉设计：

1. 先显示上一段位奖牌，例如黄金奖牌，透明度降到 40%。
2. 上一段位奖牌向下滑出 6px，同时淡出。
3. 当前段位奖牌出现，例如白银奖牌，亮度比正常低 8%。
4. 奖牌绶带轻微下垂 1 到 2px，表达“掉段”，但不做碎裂。
5. 分数变化文字用红色，段位名用当前段位颜色。
6. 不出现星点和彩带，避免把掉段误读成庆祝。

掉段判定：

- 上一版本 82 分、当前版本 76 分：`铂金 -> 黄金`，显示“掉到黄金”。
- 上一版本 71 分、当前版本 69 分：`黄金 -> 白银`，显示“掉到白银”。
- 上一版本 75 分、当前版本 72 分：仍是黄金，只显示掉分，不显示掉段。

掉段后仍显示当前段位奖牌，不显示上一段位奖牌作为最终状态，避免用户误会当前等级。

### 同段位掉分反馈

当分数下降但段位不变时，不显示“掉段”，只给轻提醒：

- 奖牌轻微暗一下，然后恢复。
- 文案提醒别让小问题继续扣分。
- 示例：`黄金还在，但这版被小问题偷了几分。`

### 同段位涨分反馈

当分数上涨但段位不变时，反馈要比晋级弱：

- 奖牌轻微发亮一次。
- 文案强调“离下一档更近”。
- 示例：`黄金段位稳住了，距离铂金更近一步。`

## 右上角布局建议

```text
V18 -> V19  +16
```

布局要求：

- 当前预览版本中，右上角只保留版本范围和分数变化，不显示“当前等级”、奖牌图标或等级名称。
- 分数变化字号与上方指标按钮文字一致，保持一行纯文本，不再做胶囊、徽章或卡片嵌套。
- 等级仍用于折线点和悬浮卡片的颜色区分，但颜色需要收敛到系统主紫色的相近色系，避免金色、铜色等跳出整体界面。
- 悬浮卡片可以保留对应等级的背景色，但卡片标题中不显示等级名称和奖牌图标。
- 当前项目只有一个有分数版本时，不显示这块段位反馈。
- 新增内容默认不要做“卡片套卡片”的嵌套样式。除非它是按钮，或者有明确提示词、警告、确认等需要被强调的内容，否则优先用直接排版、文本、图标和轻量间距表达。

## 实现顺序

1. 建立前端段位配置表：分数区间、段位名、奖牌色、中心符号、短评语料。
2. 只接入历史版本对比页右上角分数变化区域。
3. 计算当前最新版本段位，并和上一个有分数版本比较。
4. 先实现静态 SVG 奖牌和普通短评。
5. 再加入四种状态：晋级、同段涨分、同段掉分、掉段。
6. 掉段状态要优先于普通掉分状态显示。

## 注意事项

- 段位是游戏化反馈，不是正式评分标准。
- 文案可以有竞争感，但不能羞辱用户。
- 低分也要给“可以继续冲”的感觉。
- 奖牌图标和文案要放进统一配置，方便后续调整。
