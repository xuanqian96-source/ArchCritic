# ArchCritic P0 可视化验证设计

> **状态**：已确认，直接进入实现

## 这次先做什么

先完成 P0 最小闭环，让系统具备三件事：

1. 后端可以启动，并保存基础数据。
2. 后端可以返回一份结构化评图结果，先用演示数据代替真实建筑学数据。
3. 前端提供一个简单页面，可以录入内容并直观看到结果。

## 为什么这样做

当前仓库只有健康检查接口，离“能看见系统工作”还差很多。  
这次不先追求真实评图质量，而是先把完整流程打通，方便后续替换成真实 Prompt、真实知识库和真实模型。

## 最小范围

- 后端：补齐数据库、数据模型、项目与提交接口、演示评图接口、LLM 封装层。
- 前端：补齐 React + Vite 页面，提供表单、项目列表、评图结果展示。
- 文档：补齐上下文、说明文档、架构说明。

## 可视化验证方式

启动前后端后，在浏览器里打开页面：

1. 输入一个演示项目名称和设计说明。
2. 选择一个设计阶段。
3. 点击按钮生成评图结果。
4. 页面直接显示评分、问题、建议和亮点。

只要页面能稳定显示结果，就说明 P0 的基础闭环已经建立。
