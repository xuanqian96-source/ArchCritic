公共建筑设计教学辅助平台

不止于评图 陪伴完整的 设计学习过程

ArchCritic 将原本分散在课程知识、案例参考、设计实践和评图反馈中的学习过程连接起来，让学生在设计前建立认知，在设计中查找方法，在评图后理解问题，并把反馈带回下一轮修改。

教学定位与愿景

从学会原理， 到反馈迭代 设计方案

学生先学习公共建筑设计原理，再通过优秀案例理解原理如何落地，然后把知识用于自己的设计，最后通过 AI 评图发现问题，回到知识和案例中继续学习与修改。

教学辅助方式

围绕真实设计过程 串联知识与实践 形成连续反馈

学生在设计前学习原理、理解案例，在推进中查找方法，在评图后回到具体知识点继续学习；每一轮报告与修改记录共同形成连续的复盘线索。

01

知识学习

按主题与层级理解公共建筑设计原理，通过知识测试检查自己的掌握情况。

02

案例理解

从公共建筑案例中观察场地、功能、流线、空间、形式与结构策略如何落地。

03

设计实践

结合课程任务书、项目阶段和设计图纸，为每一轮方案建立真实评图上下文。

04

反馈与复盘

通过 AI 评图发现问题、追问原因、查找知识，并在历史版本中回看修改过程。

智能体 评图 角色

智能体系统

七大评审 Agent 按设计阶段参与评图

不同评审 Agent 分别关注功能流线、图面表达、场地回应、结构与设计概念，并由综合评审汇总问题优先级，形成面向当前设计阶段的协同反馈。

功能

功能与流线 Agent

检查空间组织、功能关系、公众与后勤流线，以及主要使用路径是否清晰。

表达

图面表达 Agent

检查图纸完整度、信息层级、标注排版和整体阅读效率。

场地

场地 Agent

分析基地条件、交通组织、城市界面，以及建筑对周边环境的回应。

结构

结构 Agent

核对结构体系、跨度、受力逻辑与构造合理性，识别影响方案落地的问题。
